# Editor de PDF — Windows Portable v0.2.3

Interface moderna e acessível do Editor de PDF para Windows.

## Novidades v0.2.3
- Pré-visualização ajustada para **encaixar a página inteira automaticamente**.
- A área central ganha mais espaço vertical e não é forçada pelo tamanho natural da imagem.
- Coluna **Ações** mais larga e compacta, com todos os comandos de edição legíveis.
- Botões de importação e edição redimensionados para evitar cortes em telas menores.
- Área de arrastar e soltar mais compacta.
- Painel de configurações refinado, com capa e informações melhor distribuídas.
- Faixa inferior de páginas reduzida para liberar mais espaço para a pré-visualização.
- Miniaturas menores, mais equilibradas e com melhor aproveitamento horizontal.

## Mantido
- Selecionar corte, remover recorte, girar e excluir fora da imagem.
- Ctrl+Z para desfazer recorte, remoção de recorte, giro e exclusão.
- Tema escuro moderno.
- Drag & drop de imagens e PDFs.
- Reordenação pelas miniaturas.
- Capa padrão opcional, sempre inteira e sem corte.
- Páginas internas com largura padronizada e altura automática.
- Qualidade Alta / Média / Compacta.
- Ícone moderno no aplicativo e no executável.
- Publicação direta em GitHub Releases, sem Actions Artifacts.

## Build
O workflow pode ser executado manualmente e também gera automaticamente a Release quando a versão é atualizada na branch `main`.

**Actions → Build Editor de PDF - Windows → Run workflow**

Release: `v0.2.3`.
