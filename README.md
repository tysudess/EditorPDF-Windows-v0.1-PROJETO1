# Editor de PDF — Windows Portable v0.3.1

Versão refinada do layout moderno aprovado para o Editor de PDF no Windows.

## Novidades v0.3.1
- Layout reproduzido a partir da prévia aprovada.
- Removido o bloco de dica abaixo da área de arrastar e soltar.
- A faixa **PÁGINAS** agora fica alinhada somente com a **PRÉ-VISUALIZAÇÃO**.
- Coluna esquerda ocupa toda a altura e ganhou mais espaço útil.
- **EDIÇÃO DA PÁGINA** refeita com cards quadrados, ícones vetoriais maiores e textos separados.
- Botões de recorte e giro não ficam mais sobrepostos.
- **Excluir página** permanece em botão horizontal destacado.
- Pré-visualização, zoom e Ajustar mantidos.

## Mantido
- Ctrl+Z.
- Drag & drop de imagens e PDFs.
- Reordenação pelas miniaturas.
- Capa padrão opcional sempre inteira e sem corte.
- Geração inteligente do PDF e qualidades Alta / Média / Compacta.
- Publicação direta em GitHub Releases.

Release: `v0.3.1`.
