# Editor de PDF — Windows Portable v0.3.0

Nova interface visual do Editor de PDF para Windows, baseada no modelo moderno aprovado.

## Novidades v0.3.0
- Layout renovado em tema escuro com acabamento mais moderno.
- Ferramentas de edição em **botões quadrados com ícones**, organizadas em grade 2x2.
- **Excluir página** em botão próprio, destacado e mais fácil de identificar.
- Pré-visualização central ampliada e limpa.
- Controles de **zoom - / +** e botão **Ajustar** para voltar ao encaixe da página inteira.
- Indicador de zoom atualizado automaticamente.
- Área **IMPORTAR** reorganizada.
- Botão **Adicionar páginas** na faixa inferior.
- Painéis, bordas, espaçamentos e hierarquia visual refinados.
- Botões **Exportar PDF** e **Gerar PDF** com destaque em gradiente azul/roxo.

## Mantido
- Ctrl+Z para desfazer recorte, remoção de recorte, giro e exclusão.
- Drag & drop de imagens e PDFs.
- Reordenação pelas miniaturas.
- Capa padrão opcional, sempre inteira e sem corte.
- Páginas internas com largura padronizada e altura automática.
- Qualidade Alta / Média / Compacta.
- Ícone moderno no aplicativo e no executável.
- Publicação direta em GitHub Releases, sem Actions Artifacts.

## Build
O workflow pode ser executado manualmente e também publica automaticamente a Release quando a versão é atualizada na branch `main`.

**Actions → Build Editor de PDF - Windows → Run workflow**

Release: `v0.3.0`.
